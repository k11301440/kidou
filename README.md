# KIDOU（試作プロトタイプ v0.5.0）

未知の言語を自分の辞書で解読しながら、失われた遺跡の未知装置を段階的に起動していくAndroidゲーム（Kotlin / Jetpack Compose）。

## v0.5.0 の主な実装内容

- **ボード5 全25問実装・ボード1〜4 文脈強化（全125レベル）**:
  - ボード5（`5-1`〜`5-25`）をすべてプレイ可能な本番パズルとして実装（計125レベル・すべて制限時間なし／ペナルティなし）。
  - 連動スイッチ、ダイヤル／バルブ一致・合計条件、周期信号（長押し複合含む）、記憶モードを組み合わせた総仕上げ構成。
  - ボード1〜4の既存レベルにも語彙手がかりを追加し、各単語の出現機会を拡充。
- **RTAモード（自動生成10問タイムアタック）**:
  - ボード5 最終問題（`5-25`）クリア後、タイトル画面に「RTA」モードが解禁。
  - 既存の記号文法・語彙のみを使う逆算型プロシージャルジェネレーター（`RtaLevelGenerator`）が毎回10問を自動生成し、`LevelEngine` シミュレーションで解法実在を検証した問題のみ出題。
  - 単調増加クロック（`SystemClock.elapsedRealtime()`）によるタイム計測・クリア時「自己ベスト更新」バッジ・永続ベストタイム保存に対応。
- **Google Play Games Services v2 対応（実績・クラウドセーブ）**:
  - タイトル画面・メニュー「設定」に公式 Play Games コントローラーアイコン付きのオプトイン連携UIを実装（未連携・オフライン環境でも全機能プレイ可能）。
  - 進捗／辞書翻訳率／RTAベストに応じた12種の実績判定（`AchievementEvaluator`）と、ローカル／クラウド競合マージ（`SaveMergePolicy`：起動済みレベル和集合・辞書マージ・RTA最速値優先）。
  - Play Console 登録前はプレースホルダ（`KIDOU_PLAY_GAMES_APP_ID` / `PlayGamesConfig.kt`）で安全に動作。
- **進捗可視化・UI グリフ化整理・プライバシーポリシー公開**:
  - メニュー「進捗」タブに全体クリア進捗バー、ボード1〜5 の25マス個別クリアドットグリッド、遭遇単語／翻訳率プログレスバーを追加。
  - 説明シート／ストーリー／ボード画面の解禁ルール／レベル画面「← ボード」／単語編集画面から説明的見出し・装飾注記を整理し、五進数・グリフ表現へ統一。タイトル下部バージョン表記を `v0.5.0` へ更新。
  - プライバシーポリシーを GitHub Pages に公開し、アプリ内「設定」の外部リンクを接続（https://k11301440.github.io/kidou/privacy-policy.html ）。

## データ定義ファイル

- `app/src/main/assets/glyphs.json`: 12×12ピクセルグリフ定義（66種）
- `app/src/main/assets/words.json`: 日英対応の語彙テーブル（66語、初期セット7語含む）
- `app/src/main/assets/boards.json`: ボード1〜5（各25レベル・全125問）およびストーリー・説明グリフ定義
