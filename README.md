# KIDOU（試作プロトタイプ v0.1）

未知の言語を自分の辞書で解読しながら、失われた遺跡の未知装置を段階的に起動していくAndroidゲーム（Kotlin / Jetpack Compose）。

## 主な特徴

- **正解判定のない言語解読**: プレイヤーの翻訳に対して正誤判定を出さず、装置の状態遷移や一貫した反応の違和感から意味を推測・更新できる。
- **ライブ・ルビ反映**: どの画面・操作ログ上のグリフでもタップして訳語・分類タグ（6色）・メモを登録でき、すべての出現箇所と過去ログに即座に反映される。
- **語順とスロット構造**: `目的語 -> 動詞 -> 修飾語` 語順を基本とし、スラッシュ等の記号を使わず単語間隔とスロット間隔の差で文の骨格を示す。
- **12×12ピクセル独自グリフ**: フォント化せず12×12ドット配列データ（`app/src/main/assets/glyphs.json`）からCanvas描画。コア動詞20語（Prototype 03ベース＋押す/引く・切る・回す矢印頭を改善）と名詞・数詞・修飾語を収録。
- **データ駆動の5フェーズ構成**:
  - Phase 1: 単一ボタン
  - Phase 2: ボタン＋レバー
  - Phase 3: ダイヤル数値指定＋レバー＋ボタン
  - Phase 4: 文章手順書に沿ったシーケンス操作（誤手順でリセット）
  - Phase 5: 回路接続・鍵・ダイヤル・レバー・ボタンの複合条件起動
- **完全オフライン & シンセ効果音**: `kidou_save.json` に端末内保存、`AudioTrack` によるレトロシンセ効果音（ミュート切替対応）。

## データ定義ファイル

- `app/src/main/assets/glyphs.json`: 12×12ピクセルグリフ定義（40種）
- `app/src/main/assets/words.json`: 語彙テーブル（34語、内部意味はUIに非表示）
- `app/src/main/assets/machine.json`: 5フェーズの状態遷移マシン定義

## ビルド・テスト

```powershell
# 単体テスト実行
.\gradlew.bat testDebugUnitTest

# デバッグAPKビルド
.\gradlew.bat assembleDebug
```

生成先: `app/build/outputs/apk/debug/app-debug.apk`
