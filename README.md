# KIDOU（試作プロトタイプ v0.3.0）

未知の言語を自分の辞書で解読しながら、失われた遺跡の未知装置を段階的に起動していくAndroidゲーム（Kotlin / Jetpack Compose）。

## v0.3.0 の主な実装内容

- **5×5 ボードシステム拡張（全51レベル）**:
  - ボード1（25レベル）の20/25起動でボード2（全25レベル実装）を解禁。
  - ボード2（25レベル）の20/25起動でボード3（1問目まで実装＋ボード3ストーリー）を解禁。
  - ボード画面のクリア済みマスは五進数数字から起動完了グリフへ切り替わる。
- **新ギミック・論理回路パズル（ボード2〜3）**:
  - スイッチ（A/B/C）による AND / OR / NOT / XOR 条件、長押しボタン（HOLD）、左右スワイプ操作スライダー、2ボタン同時押し（CHORD）を追加。
- **レベル画面のUI統一と進行導線**:
  - 下部操作パーツを「左：部品種類グリフ / 右：現在状態・操作グリフ付き大型ボタン」に統一（操作で中のグリフも変化）。
  - 上部表示パネルがはみ出す場合は右端の縦スクロールバーと下端中央の `▼` 下向き矢印を表示。
  - 起動成功時の表示をグリフ＋ルビのみへ統一し、メインボタンが「次へ / NEXT」へ変化して次の問題へ直接遷移（最終問題ではボードへ戻る）。
- **タイトル画面・メニュー整理・テーマ機能**:
  - タイトル画面にデータ駆動のサブタイトル（`言語解読 × 試行錯誤` / `DECIPHER × EXPERIMENT`）と均等余白の開始パネルを配置。
  - メニューから操作ログタブ・進捗補足文を削除し、「進捗」「設定」の2タブ構成へ整理。
  - 設定画面にダーク／ライトモード切替、4種類のカラーテーマ（琥珀遺跡 / 翠走査線 / 蒼信号 / 紅鍛冶）、および `AppConfig.PRIVACY_POLICY_URL` によるプライバシーポリシーリンクを追加。
- **辞書・広告・音声（v0.2.0 継続機能）**:
  - 単語登録時の自動フォーカス＆キーボード表示、未知語ストーリー・説明メニュー、日英切り替え対応。
  - Google Mobile Ads SDK (`25.5.0`) リワード広告視聴で選択中の1語の想定訳を自動登録し翻訳率へ反映（開発時はテストID、本番は `KIDOU_ADMOB_APP_ID` / `KIDOU_ADMOB_REWARDED_ID` で差し替え）。
  - 設定画面の検証用メニュー（一括想定訳付与・リセット・ボード1/ボード2の19/25起動プリセット）。
  - BGM: "Loading Screen" by Purrple Cat（CC BY 4.0 / https://opengameart.org/content/loading-screen ）

## データ定義ファイル

- `app/src/main/assets/glyphs.json`: 12×12ピクセルグリフ定義（58種）
- `app/src/main/assets/words.json`: 日英対応の語彙テーブル（58語、初期セット7語含む）
- `app/src/main/assets/boards.json`: サブタイトル、説明文、ボード1（25レベル）＋ボード2（25レベル）＋ボード3（1レベル）定義

## ビルド・テスト

```powershell
# 単体テスト実行
.\gradlew.bat testDebugUnitTest

# デバッグAPKビルド
.\gradlew.bat assembleDebug
```

生成先: `app/build/outputs/apk/debug/app-debug.apk`
