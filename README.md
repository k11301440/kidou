# KIDOU（試作プロトタイプ v0.2.0）

未知の言語を自分の辞書で解読しながら、失われた遺跡の未知装置を段階的に起動していくAndroidゲーム（Kotlin / Jetpack Compose）。

## v0.2.0 の主な実装内容

- **5×5 ボードシステム**: 1ボード＝25レベルを最初から全開放。25問中20問を起動するとボード2（1問目まで実装）が解禁される。
- **五進数表記**: 数字グリフ（0〜4）を基本単位とし、レベル番号・装置目標値（5＝`10`、20＝`40`、25＝`100`）をすべて五進数のグリフのみで表現。
- **新規設計した25＋1レベル**: ボタン回数からレバー・鍵・回路・錠・否定、ダイヤル／弁の数値指定、順番シーケンス（誤手順はソフトリセットで失敗状態なし）、複合条件へ段階的に展開。
- **タイトル画面**: 画面全体を斜め・複数行でスクロールし続けるグリフ背景演出を実装。
- **単語登録の操作性向上**: 単語登録シートを開くと同時に訳語入力欄へ自動フォーカス＆キーボード自動表示。
- **ストーリー & 説明メニュー**:
  - ボードごとの未知語ストーリー表示（第1ボードの語彙のみ初期セットの訳を付与、翻訳率からは除外）
  - 解禁ルール（100のうち40起動なら次の盤が開く）を示す未知語の説明メニュー
- **リワード広告による想定和訳開示**: Google Mobile Ads SDK (`25.5.0`) テスト広告を最後まで視聴すると、選択した1語の想定和訳を辞書へ自動登録し翻訳率に反映（回数無制限、本番IDは Gradle プロパティ `KIDOU_ADMOB_APP_ID` / `KIDOU_ADMOB_REWARDED_ID` で差し替え可能）。
- **検証用デバッグメニュー**: 設定画面下部に「全単語へ想定訳を一括付与」「一括付与リセット」「ボード1を19/25起動済みにする」を通常導線と分離して配置。
- **日英切り替え**: UI表示と想定翻訳（初期セット・広告開示・検証一括付与）を日本語／英語で切り替え可能（プレイヤー自身の登録テキストは維持）。
- **BGM & クレジット**:
  - `res/raw/loading_screen.ogg` をループ再生（メニュー・タイトル画面でミュート切替対応）
  - BGM: "Loading Screen" by Purrple Cat（CC BY 4.0 / https://opengameart.org/content/loading-screen ）
- **アプリアイコン**: ゲーム内の「ボタン」グリフを元にしたアダプティブアイコンへ刷新。

## データ定義ファイル

- `app/src/main/assets/glyphs.json`: 12×12ピクセルグリフ定義（49種）
- `app/src/main/assets/words.json`: 日英対応の語彙テーブル（49語、初期セット7語含む）
- `app/src/main/assets/boards.json`: 説明文、ボード1（25レベル）＋ボード2（1レベル）定義

## ビルド・テスト

```powershell
# 単体テスト実行
.\gradlew.bat testDebugUnitTest

# デバッグAPKビルド
.\gradlew.bat assembleDebug
```

生成先: `app/build/outputs/apk/debug/app-debug.apk`
